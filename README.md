# loickch.github.io

Personal research site. Built with [Jekyll](https://jekyllrb.com/), based on the
[al-folio](https://github.com/alshedivat/al-folio) theme.

Ruby **3.2.2** — matches `.github/workflows/deploy.yml`. Anything older fails:
the dependency tree resolves `activesupport 8.x`, which requires `>= 3.2.0`.

## Setup

### Option A — conda / micromamba (no sudo)

Preferred on shared machines and clusters. Installs Ruby, a compiler toolchain
and ImageMagick into an isolated env without touching the system.

```bash
micromamba create -y -n jekyll -c conda-forge ruby=3.2 compilers make imagemagick pkg-config
micromamba run -n jekyll bundle config set --local path vendor/bundle
micromamba run -n jekyll bundle install
```

### Option B — rbenv (needs sudo)

```bash
zsh setup_homepage.sh
```

## Running the dev server

```bash
micromamba activate jekyll
bundle exec jekyll serve --livereload      # http://127.0.0.1:4000
```

Or as a one-liner without activating:

```bash
micromamba run -n jekyll bundle exec jekyll serve --livereload
```

Useful flags:

| Flag | Why |
|---|---|
| `--livereload` | reload the browser on save |
| `--port 4001` | if 4000 is taken |
| `--incremental` | faster rebuilds while writing a post |
| `--drafts` | also render `_drafts/` |

Build without serving (what CI runs):

```bash
micromamba run -n jekyll bundle exec jekyll build
micromamba run -n jekyll bundle exec jekyll clean   # wipe _site + caches
```

A clean build should report **0 conflicts and 0 errors**. The remaining
`DEPRECATION WARNING` lines about Sass `@import` and `lighten()` are upstream
al-folio notices for Dart Sass 3.0; they do not affect the output.

## Notes

- `mini_racer` is deliberately **not** in the `Gemfile`. It ships a precompiled
  binary needing glibc ≥ 2.38 and fails to load on older hosts. `jekyll-minifier`
  reaches JS minification through `terser` → `execjs`, which picks up Node.
  Make sure `node` is on `PATH`.
- The `*-480/-800/-1400.webp` files under `assets/img/` are generated by
  `jekyll-imagemagick` on every build. They are gitignored and excluded in
  `_config.yml`; do not commit them.
- If images fail to convert, check ImageMagick is present: `magick -version`
  (or `sudo apt install imagemagick` outside the conda env).

## Deployment

Pushing to `main` triggers `.github/workflows/deploy.yml`, which builds with
Ruby 3.2.2, runs purgecss, and publishes `_site` to `gh-pages`.
